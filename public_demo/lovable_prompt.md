# Lovable Prompt For AyunOS Public Demo

Build a clean landing page and mock dashboard for AyunOS.

AyunOS is a local-first second brain for importing AI conversation exports into a local SQLite memory database, then reviewing them with search, tags, marks, and lightweight organization.

Use mock data only. Do not request, upload, process, or display private data. Do not use real user records, real conversation titles, real messages, personal screenshots, raw exports, or generated databases.

## Pages

1. Landing
2. Memory Browser Demo
3. Privacy-first Architecture
4. Roadmap

## Style

- White Codex-like minimal interface.
- Calm technical feeling.
- Soft gray borders.
- Rounded cards.
- Spacious layout.
- Minimal shadows.
- Monospace accents for ids, tags, and local database concepts.
- No flashy gradients.
- No cyberpunk.
- No cartoon mascot.
- No heavy SaaS marketing style.

## Data

Use the mock memory items from `mock_memory_items.json`. Show cards with title, type, updated time, message count, tags, summary, and privacy level.

## Sections To Include

- Hero: "Your local-first memory workspace."
- Product explanation: importer, SQLite memory database, search, tags, marks, review workflow.
- Mock memory browser dashboard.
- Privacy-first architecture diagram using local-only language.
- Roadmap: local browser, review workflow, optional future AI-assisted summarization, exportable notes.
