# AyunOS Website Review Checklist

## Privacy

* Does not ask users to upload real ChatGPT exports
* Does not show real conversation titles
* Does not show real user names
* Does not show real local paths
* Does not mention private database files directly
* Uses mock data only

## Visual Style

* White background
* Soft gray borders
* Rounded cards
* Minimal shadow
* Spacious layout
* Calm technical feeling
* No cyberpunk
* No neon
* No cartoon mascot
* No heavy SaaS hype

## Product Accuracy

* Clearly says AyunOS is local-first
* Clearly says private data stays local
* Describes import / search / tags / marks / review workflow
* Says AI summarization is future / optional
* Does not imply cloud sync is required

## Copywriting

* Tone is quiet, precise, serious
* No exaggerated AGI / revolution language
* No overpromising
* No fake customer logos
* No fake metrics
