# Canva Brand Brief For AyunOS

Create simple public-facing brand assets for AyunOS using mock data only. Do not use real user data, real conversation text, personal screenshots, raw exports, generated databases, or private records.

## Logo Direction

- Minimal wordmark: `AyunOS`
- Optional small symbol inspired by a local memory node, database card, or quiet workspace grid.
- Avoid mascots, cyberpunk marks, and overly decorative AI symbols.
- Prefer a precise, calm, technical feel.

## Social Preview Image

- Size: 1200 x 630.
- White or very light gray background.
- Headline: "AyunOS"
- Subtitle: "A local-first memory workspace for AI conversations."
- Include a simplified mock dashboard card with 3-4 fake memory items.
- Use mock tags such as `project`, `study`, `tech`, and `review`.

## Product Card

- A compact card suitable for a landing page or social carousel.
- Show the workflow: Import locally -> Search -> Tag -> Review.
- Keep the interface white, spacious, and restrained.

## Visual Style

- Background: `#FFFFFF`
- Surface: `#F8FAFC`
- Border: `#E5E7EB`
- Text primary: `#111827`
- Text secondary: `#6B7280`
- Accent: `#2563EB` or `#6366F1`
- Rounded cards, subtle borders, minimal shadows.

## Hard Boundaries

- No real user data.
- No personal screenshots.
- No raw export screenshots.
- No private database screenshots.
- No real conversation titles or message content.
