# AyunOS Visual Style

The AyunOS public demo should feel like a clean technical workspace: calm, readable, and trustworthy. It should look closer to a polished developer tool than a flashy SaaS campaign.

## Direction

- Clean white Codex-like interface.
- Calm technical feeling.
- White background.
- Soft gray borders.
- Rounded cards.
- Minimal shadows.
- Spacious layout.
- Monospace accents for ids, tags, commands, and database concepts.
- No flashy gradients.
- No cyberpunk styling.
- No cartoon mascot.
- No heavy SaaS marketing style.

## Suggested Palette

- Background: `#FFFFFF`
- Surface: `#F8FAFC`
- Border: `#E5E7EB`
- Text primary: `#111827`
- Text secondary: `#6B7280`
- Accent blue: `#2563EB`
- Accent indigo: `#6366F1`

## UI Components

- Top navigation with restrained typography.
- Hero section with a short product promise and mock dashboard preview.
- Memory cards with title, type, tags, updated time, and summary.
- Architecture section with simple local-first flow.
- Roadmap cards for importer, browser, review workflow, and future AI assistance.

## Typography

Use a neutral sans-serif for body text and a monospace accent for technical labels. Keep line lengths comfortable and avoid dense marketing copy.
