# AyunOS 路线图（历史入口）

本文件原先记录“本地资料整理、DeepSeek 接入、本地模型”三个早期产品阶段。该三阶段描述是
项目早期草案，不再作为当前版本节点、生产迁移或发布授权的依据。

当前权威路线见
[`design/yunos_authoritative_roadmap.md`](design/yunos_authoritative_roadmap.md)：

`v9.0.1 -> v10.0 -> v10-A -> v10-B -> v10-C -> v10-D -> v10-E -> v10-F`

v10-F 是当前路线的最终封板节点，完成后立即停止。本路线不创建 v10-G、v10.1 或 v11，
不重新开启 Historical Reconstruction，不应用 `v8302`，也不激活
`preserved_out_of_scope_engineering`。新的版本方向只能由未来独立用户授权建立，不能由
当前 Agent 自行延伸。
