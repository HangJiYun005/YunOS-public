# YunOS

**给文字一个随时找得到的家。**

微信里复制的重要消息、文章里留下的一段摘录、工作中的临时记录，都可以保存到 YunOS。需要时输入关键词，找到资料，接着读原文。

资料保存在自己的电脑上，不需要账号，也不需要配置 AI 服务。

## 双击就开始

**[下载 Start-YunOS.bat](https://github.com/HangJiYun005/YunOS-public/releases/download/v0.2.2/Start-YunOS.bat)**，保存后双击。

首次启动会自动下载程序和独立运行环境（网络中断时自动重试，最多 3 次），完成后打开 YunOS。无需自行安装 Python、Node.js 或 Git，不需要管理员权限。之后仍然双击这个 BAT；本机环境已准备好时，使用资料库不需要联网。

也可以下载 [完整启动包 ZIP](https://github.com/HangJiYun005/YunOS-public/releases/download/v0.2.2/YunOS-0.2.2.zip)，解压后双击其中的 BAT。首次仍需下载运行环境。

适用范围是 **Windows 10 / 11**，首次下载需能连接 GitHub 和 python.org。BAT 不是 macOS 或 Linux 的启动方式。目前已在 Windows x64 上实测；x86 / ARM64 下载分支尚未在对应实机验收。

## 把资料放进来

打开左下角 **设置 → 资料导入**：

1. **选择文件或拖进框里**：支持 TXT、Markdown，也可以一次选择多个文件。
2. **或者直接粘贴**：把微信消息、网页摘录或随手记贴进正文，标题可以留空。
3. **检查并预览**：先看内容、编码和重复提示，再点“确认导入”。

相同正文只保存一次，同时保留不同来源。文件同名但内容不同，会各自保存，不覆盖已有资料。空文件、不支持的格式和读取失败都会明确提示。

每个文件最多 5 MB，每批最多 50 个、总计 10 MB。中文编码支持 UTF-8、GB18030 / GBK 和带 BOM 的 UTF-16；自动识别不正确时，可以手动选择后重新预览。

## 保存后怎么找

首页搜索默认覆盖**全部资料**。输入原文中的词语，就能查看相关内容；点开卡片可阅读完整原文和来源。`Ctrl+K` 可以快速进入搜索框。

目前使用本地关键词/子串搜索，不调用外部模型，也不产生模型费用。资料量很大时，搜索速度仍有优化空间。

界面沿用浅色、蓝灰色调，并保留设置展开、二级页面切换、拖拽高亮和结果出现的过渡动画；启用系统“减少动态效果”时会自动减弱动画。

## 数据和备份

资料库默认保存在 `%LOCALAPPDATA%\YunOS\data`，与程序文件分开。重新下载程序不会重建或清空资料。

在 **设置 → 本地数据** 中查看保存位置、下载完整备份，或退出本机服务。仅关闭窗口不会停止后台服务。

不同电脑之间不会自动同步。要恢复备份，请先退出服务，保留原数据库副本，再按 [安装和使用教程.txt](安装和使用教程.txt) 的步骤替换资料库。

## 当前版本的边界

- 支持普通文字、TXT 和 Markdown；微信内容目前通过复制粘贴或已有文字文件导入。
- 不自动读取微信，不支持图片/语音识别、PDF、Word 或聊天 ZIP 解析。
- 程序优先使用已安装的 Edge / Chrome 打开独立应用窗口；找不到时使用默认浏览器。
- 新公开版采用独立资料库，不会自动读取或迁移旧版私人数据库。

仓库中的旧架构代码保留用于开发参考，**不进入本版启动包，也不会由新入口加载**。日常使用以本 README 和根目录 TXT 教程为准。

## 开发与验证

新的运行入口和界面位于 `public_app/`，只使用 Python 标准库。

```powershell
python public_app/server.py --data-dir ./output/dev-library
python -m unittest discover -s tests_public -v
```

启动脚本位于 `scripts/start_public.ps1`。运行环境固定版本并按 [Python 官方发布页](https://www.python.org/downloads/release/python-31410/) 的 SHA-256 校验；应用下载包也核对发布校验文件。

功能取舍及本轮验收说明见 [公开版改造记录](docs/public-edition-review.md)。
