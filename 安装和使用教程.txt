YunOS 安装和使用教程（公开版 0.2.2）
===================================

一、第一次打开

1. 下载 Start-YunOS.bat：
   https://github.com/HangJiYun005/YunOS-public/releases/download/v0.2.2/Start-YunOS.bat
2. 把它保存到桌面或自己容易找到的位置，再双击。
3. 第一次需要联网。程序会下载自身文件和独立 Python 运行环境，
   校验后自动启动。你不需要手工安装 Python、Node.js、Git 或数据库。
4. 有 Edge / Chrome 时优先打开独立应用窗口，否则打开默认浏览器。
5. 以后双击同一个 BAT 即可。下载完成后，日常保存、阅读和搜索可离线使用。

也可以下载完整启动包 ZIP，解压后双击其中的 Start-YunOS.bat。
不要直接在压缩包预览窗口里运行；先解压。

系统范围：Windows 10 / 11。BAT 不能直接用于 macOS 或 Linux。
已在 Windows x64 测试；x86、ARM64 对应下载分支尚未做实机验收。
首次需要能连接 GitHub 和 python.org。网络不通时会显示错误，不会清空资料。
如果下载受到公司策略或安全软件限制，不要关闭安全软件，先核对限制原因。

二、导入文件

1. 点击左下角“设置”。
2. 在设置中进入“资料导入”。这是设置里的二级页面，不是另一个小程序。
3. 在“导入文件”中点击虚线框选择文件，也可以把文件直接拖到框内。
4. 支持 TXT、MD、Markdown。每个最多 5 MB；每批最多 50 个、合计 10 MB。
5. 可选填写来源，编码通常保持“自动识别”。
6. 点击“检查并预览”，核对文字和结果。
7. 点击“确认导入”。界面会显示新增、重复、失败的数量。

当前不支持直接解析 PDF、Word、图片、音频、微信数据库和聊天 ZIP。
需要保存这些材料中的文字时，可以先复制正文，再用“粘贴文字”。
Markdown 当前按文字显示，保留原文，不执行其中的 HTML 或脚本。

三、保存微信消息或随手记录

1. 在微信或其他软件里自行复制需要保存的文字。
2. 进入“设置 → 资料导入 → 粘贴文字”。
3. 粘贴正文，标题可以留空；留空时会使用正文第一行的简短片段。
4. 来源可以选“微信”“网页”“手动记录”等。
5. 检查预览后确认导入。

程序不会后台监视剪贴板，不自动读取微信，也不会猜测消息的发言人和时间。
如果这些信息对你重要，可以一起复制到正文中。

四、重复导入如何处理

- 按正文内容检查，不是只比较文件名。
- 相同文字、不同文件名：不再增加正文，保留来源信息。
- 同名文件、不同文字：分别保存，不覆盖已有资料。
- Windows/Unix 换行和常见 Unicode 表示差异会做统一处理。
- 其他文字、空格或内容发生变化时，可能被视为不同资料。
- 同一批内重复、以后再次导入、重复点保存，都会检查重复。
- 预览不写入数据库；修改输入后需要重新预览。
- 预览有效期为 10 分钟，过期后重新检查即可。
- 空文件或格式错误会单独列出；其他有效文件仍可确认导入。

五、搜索和阅读

回到主页面，在搜索框输入关键词。默认搜索全部资料，没有私人记忆分区。
支持中文原文中的短词，也支持标题搜索。Ctrl+K 可以快速聚焦搜索框。
点击结果卡片阅读原文；右上角关闭阅读窗口可以返回列表。

目前是本地关键词/子串搜索，不是 AI 语义搜索，不能保证理解改写后的意思。
搜索不到时，试试原文里实际出现过的词。

六、数据保存在哪里

默认数据目录：
   %LOCALAPPDATA%\YunOS\data

在文件资源管理器地址栏粘贴上面的路径即可打开。
主要文件是 library.sqlite，其他 service 文件用于本机服务协调。
不要在服务运行时移动或替换数据库。

自动下载的程序和运行环境也位于 %LOCALAPPDATA%\YunOS 下，但与 data 分开。
重新下载启动包不会覆盖资料。删除整个 YunOS 目录则会丢失资料，操作前应备份。
更换电脑不会自动带走旧电脑的资料。

七、备份、恢复和退出

备份：设置 → 本地数据 → 下载完整备份。
备份使用 SQLite 的备份机制，包含已经成功保存的正文和来源。
备份是私人资料，请放在可信位置。

恢复：
1. 在“设置 → 本地数据”中退出本机服务。
2. 确认服务已经结束，并关闭窗口。
3. 把 data 目录整体复制一份作为回退备份。
4. 确认 data 目录内没有 library.sqlite-wal 和 library.sqlite-shm 文件。
   若它们仍存在，不要直接替换或删除，先排查服务是否完全退出。
5. 将备份的 .sqlite 文件复制到 data 目录，并命名为 library.sqlite，
   在已备份原文件的前提下进行替换。
6. 再双击 BAT，检查资料数量和原文。

日常退出：设置 → 本地数据 → 退出本机服务。
只关闭窗口不会结束服务；再次双击 BAT 会复用已有服务。

八、常见问题

1. 第一次一直停在下载
   检查能否访问 GitHub 和 python.org。下载失败后重新双击即可重试。
   不需要自行下载第三方 Python 安装包，也不需要管理员运行。

2. 出现乱码
   在预览页面把编码改为 UTF-8、GB18030/GBK 或带 BOM 的 UTF-16，重新检查。
   自动识别只是尝试，最终以你看到的预览内容为准。

3. 提示预览过期或会话失效
   重新检查；服务重启后刷新页面，再继续导入。

4. 文件不支持或太大
   先转换为 TXT/Markdown，或拆分成较小文件后导入。

5. 下载校验失败
   不会继续使用未通过校验的文件。检查网络后重试，或重新下载启动包。

6. 程序没有打开
   查看 BAT 窗口中的错误。启动日志位于 %LOCALAPPDATA%\YunOS\logs。
   已保存数据仍在 data 目录，不要为了修复启动而删除整个目录。

7. 为什么关闭动画变少了
   如果系统启用了“减少动态效果”，程序会相应减弱过渡动画。

8. 旧版数据库怎么办
   本版使用新的独立资料库，不自动改动旧版五库。
   旧库直接迁移尚未实现；不要把旧数据库直接重命名成 library.sqlite。
